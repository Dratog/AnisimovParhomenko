# API сервиса заказов

Карточка заказа содержит `id` (номер заказа), `account_id` (ID клиента),
`item` (название или описание товара), `quantity` (количество) и `created_at`
(дата и время создания в формате ISO 8601).

## POST /orders

Тело запроса — JSON с обязательными полями:

```json
{"account_id": 1, "item": "Кофемолка", "quantity": 2}
```

`quantity` должно быть не меньше 1. Успешный ответ — **201 Created** и
созданная карточка заказа:

```json
{"id": 1, "account_id": 1, "item": "Кофемолка", "quantity": 2, "created_at": "2026-09-24T12:00:00"}
```

Ошибки:

- **422 Unprocessable Entity** — отсутствует обязательное поле или `quantity < 1`.
- **404 Not Found** — клиент с указанным `account_id` не существует. Проверка
  клиента по HTTP предусмотрена будущей карточкой 1.5 и пока не реализуется.

## GET /orders/{id}

`id` — номер заказа в пути. Тело запроса не требуется. Успешный ответ —
**200 OK** и карточка заказа той же структуры, что в ответе на `POST /orders`.

Ошибки:

- **404 Not Found** — заказ не найден; сообщение содержит запрошенный `id`.
- **422 Unprocessable Entity** — `id` не является целым числом.

## GET /orders?account_id=<id>

`account_id` — обязательный ID клиента в строке запроса. Необязательный `limit`
ограничивает число возвращаемых заказов: по умолчанию 50, допустимы значения
от 1 до 200. Тело запроса не требуется.

Успешный ответ — **200 OK** и JSON-массив карточек заказов указанного клиента.
Заказы возвращаются по возрастанию `id`; если их нет, ответ — `[]` с кодом 200.

Ошибки:

- **422 Unprocessable Entity** — отсутствует `account_id`, он не является целым
  числом либо `limit` не является целым числом или выходит за допустимые границы.
